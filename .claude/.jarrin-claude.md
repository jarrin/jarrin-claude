# jarrin-claude — project instructions

## Building web-interface components (`monitor/`, Nuxt UI)

When adding or changing a web-interface component in the monitor (`monitor/`, Nuxt + Nuxt UI),
consult the **`nuxt-ui`** and **`nuxt`** MCP servers first — do not write components from memory:

- **`nuxt-ui`** — look up the component before using it (`search-components`,
  `get-component`, `get-component-metadata` for props / slots / emits), reuse a matching
  example or template (`list-examples` / `get-example`, `list-templates` / `get-template`),
  and find icons with `search-icons`. Prefer an existing `U…` component over a hand-rolled one.
- **`nuxt`** — framework questions (pages, server routes, config, modules, deployment) go to
  `get-documentation-page` / `list-modules` / `get-module`, not to recall.

The MCP tools are deferred; load the ones you need in one `ToolSearch` call.
